# 查分器授权与回调

## 一、链路作用

**实施状态（2026-11-17）：待接入。** 本轮仅验证微信/华立 NET 采集，不代表水鱼或落雪 OAuth 已接入；平台凭据、兑换、刷新及域名回调仍按下文设计实施。

让用户把水鱼或落雪账号授权给 OTOKiT，使 App 能将采集成绩上传到选定账号。授权可以先于传分完成；传分过程中发现授权过期时，由同一授权能力刷新或要求重新授权。

这里不处理微信和游戏 NET 登录，也不通过查分器下载用户成绩作为本地成绩来源。

## 二、架构规范

- 公开入口和只读授权状态归 `auth`；供应商实现分别归 `auth/divingFish`、`auth/lxns`。
- `auth` 拥有待完成授权事务、平台账号身份、权限范围、凭据保存、刷新及失效策略；依赖 `network / storage`。
- UI 负责发起浏览器或系统交互，回调入口只把 URI 交给 `auth` 验证，不在 Activity 中兑换和保存 Token。
- `transfer` 通过公开授权能力请求指定账号和权限的有效凭据；不得读取存储，也不得自行刷新。需要交付凭据时限制在请求执行边界，不放入 UI 状态、任务日志和任务持久化模型。
- 每个平台账号的刷新只能有一个正在执行的操作，其他请求等待同一结果。账号切换必须产生可识别的授权代次，旧任务不能默默使用新账号凭据。

## 三、如何实现

### 1. 先验证回调方案

当前优先尝试本机回环 HTTP：App 在 `127.0.0.1` 绑定可用端口，先确认监听成功，再打开系统浏览器授权。回调只接收指定路径，交付结果后关闭监听；超时、拒绝、取消时同样释放。

水鱼文档允许登记 `http://127.0.0.1/callback` 或 `http://[::1]/callback`，匹配时忽略端口，协议、路径和查询串仍需匹配。`localhost` 不适用端口豁免。这项协议支持不等于 Android 浏览器与后台监听已验证可用。

若该实验不可靠，等待 `otokit.cn` 就绪后改用 HTTPS App Links：网站发布 `/.well-known/assetlinks.json`，关联真实包名和安装包签名指纹；App 声明精确的域名和回调路径。域名验证通过后，再测试浏览器授权返回。HTTPS 页面可保留“返回 App”的兜底按钮，但网页自动跳转不能作为唯一保证。

网站只转交授权码、state 或授权错误，不代替 App 保存或兑换用户凭据。即使网页通过自定义 scheme 回跳，兑换时的 `redirect_uri` 仍必须等于授权请求使用的 HTTPS URI。

### 2. 授权事务

发起时创建独立事务，包含供应商、随机 state、PKCE verifier、实际 redirect URI、发起时间和过期时间。使用 S256 challenge。单个平台同一时间只保留一笔有效的交互授权，替换旧事务时使旧回调失效。

回调校验目标地址、事务、state、有效期及成功或拒绝参数；通过后只兑换一次。冷启动也应能读取短期安全保存的待授权事务；进程丢失且事务不可恢复时提示重新授权，不猜测 verifier。

水鱼使用公开客户端方式，不向移动端内置 client secret。舞萌和中二的写入 scope 分别为 `prober.records.write`、`chunithm.records.write`，写入权限需要平台审核。落雪使用 PKCE 和所需的 `write_player` 等权限；账号身份展示所需权限另行按最小范围选择。

两家的 Token 兑换响应按各自契约解析，落雪当前令牌字段位于顶层，不能沿用旧版强制读取 `data` 的逻辑。持久化令牌、过期时间、实际授予权限和平台账号标识之后，才发布授权成功。

### 3. 刷新与失效

按过期时间提前请求刷新，并协调并发。成功后先可靠保存新令牌再交付使用。水鱼和落雪均轮换 refresh token，不能继续使用旧值；刷新结果不明确时不能无条件重放旧 refresh token。必要时转为重新授权，避免重复刷新导致凭据链失效。

网络暂时不可用、权限不足、授权撤销应是不同结果。不能把任何 HTTP 失败都解释成“未登录”，也不能无限进行 401 刷新重试。

## 四、需要注意的地方

- 原生 HTTPS 回调依赖域名关联，单写 manifest 并不足够。手工强制批准域名或强制指定包名打开只能证明 URI 处理代码可运行，不能证明自动验证成功。
- 水鱼授权码有效期为 60 秒，重复兑换可能连带吊销令牌；Activity 重建和重复网页跳转要去重。
- 当前不接入 `.top`。`.cn` 尚未具备可用 HTTPS 关联配置；不得将过去的访问失败当成永久不可用结论。
- 验收覆盖授权同意／拒绝、state 不匹配、重复回调、冷启动、超时、并发刷新、账号切换和未授予写权限。真实 Token 不进入测试快照或日志。
- 参考：[水鱼 OAuth](https://maimai.diving-fish.com/manual/docs/developer/oauth-api-document/)、[落雪 OAuth](https://maimai.lxns.net/docs/oauth-guide)、[Android App Links 验证](https://developer.android.com/training/app-links/verify-applinks)。供应商具体配置在实现时复核。
